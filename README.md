# League of Legends Player Retention & Churn Prediction

An end-to-end machine learning project analyzing player engagement, identifying behavioural patterns associated with retention, and predicting future inactivity using Riot Games match data.

## Project Status

Currently in development.

- [x] Riot Games API integration
- [x] Initial match collection
- [x] Multi-player match discovery
- [x] Raw JSON storage

- [x] Pagination
